# API reference

This reference documents every type and member a script can use.

Scripts run with the members of <xref:Qx.Scripting.ScriptGlobals> in scope, so `Room`, `Users`,
`Talk` and `OnIn` are written without a prefix. Everything else in the reference is a type those
members return or accept.

| Namespace | Contents |
| --- | --- |
| <xref:Qx.Scripting> | The script globals, queries and the panel API. |
| <xref:Qx.Game> | Game state managers for the room, inventory, friends and profile. |
| <xref:Qx.Game.Snapshots> | Immutable snapshots of game state. |
| <xref:Qx.Model> | Avatars, furni, rooms, users and other game models. |
| <xref:Qx.Model.Messages.Incoming> | Parsed incoming messages. |
| <xref:Qx.Model.Messages.Outgoing> | Composed outgoing messages. |
| <xref:Qx.Interception> | Packet interception. |
| <xref:Qx.Protocol> | Message keys and headers. |
| <xref:Qx.Platform> | The operating system and the keyboard. |
